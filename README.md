# Twitter Sentiment Analysis with LSTM

## 📝 Description
This project performs sentiment analysis on Twitter data using a Bidirectional LSTM neural network. The model classifies tweets into three categories: Positive, Negative, and Neutral.

## 🚀 Features
- Text preprocessing (HTML removal, emoji conversion, punctuation removal)
- Tokenization and padding
- Bidirectional LSTM architecture
- 88.4% accuracy on test data

## 📊 Model Architecture
- Embedding layer (100 dimensions)
- Bidirectional LSTM (128 units) with dropout
- Bidirectional LSTM (64 units) with dropout
- Dense layers with ReLU and Softmax
